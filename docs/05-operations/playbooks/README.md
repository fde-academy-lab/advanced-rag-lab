# Incident playbooks

Each opens with the **observable symptom**, not the cause. You do not know the cause yet — that
is why you are reading a playbook.

| Playbook | Symptom you noticed |
|---|---|
| [recall-dropped.md](recall-dropped.md) | A retrieval metric fell and nobody knows why |
| [search-is-broken-for-x.md](search-is-broken-for-x.md) | Users complain about a query class while the aggregate looks fine |
| [cost-spike.md](cost-spike.md) | The bill went up and nothing shipped |

Each ends with **what to write down**, because the second time this happens the useful artefact
is not the fix — it is the note saying which hypothesis was wrong and how long it cost.
