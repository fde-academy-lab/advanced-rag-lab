# Newsletter

**Takeaway:** one issue a month. Takeaways first, then each item as: what happened (with the
source and its date), why an FDE cares, and one experiment to run in this repository today.
Nothing here is reported from memory; every item links the source it was read from, and an
item nobody can source is left out.

| Issue | Month | Themes |
|---|---|---|
| [Issue 1](Newsletter-2026-09.md) | September 2026 | Harnesses as plug-in runtimes, agent sandboxes, RL for agents, cheaper long-context models, keyless sign-in for Claude Code |

## How an issue is made

1. Items arrive as threads in [Ideas](https://github.com/fde-academy-lab/advanced-rag-lab/discussions/categories/ideas)
   with the `newsletter` label, or as edits to the draft page.
2. The editor of the month checks every date and number against the source, writes the
   takeaways last, and merges.
3. The issue is announced in Announcements with the three takeaways in the post body, so nobody
   has to click to get the point.

The pipeline is a board on the account's projects page, *Newsletter Pipeline*, with the
columns Idea, Drafting and Published.
