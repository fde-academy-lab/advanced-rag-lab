# How to run the whole lab from a phone

**Takeaway:** the parts of this repository that matter most were designed for people who will
never clone it. A thread is the interface.

| Want to | On a phone |
|---|---|
| Try a drill | GitHub app or browser, Discussions, LAB Simulator, New discussion. Paste an `answer.yaml` for `RD2`, `XD1`, `ED2`, `ED3` or `FD1`; those need no code at all |
| Ask something | Q&A, with what you tried. Marking the answer later is one tap |
| Read this week | The repository README's "Where to go next", or the Pulse board |
| Get the next hint | Comment `/hint` on your own thread |
| See your own progress | Comment `/progress` |
| Read the paper of the week | Reading Club threads link the note; the note links the paper |

**Not from a phone:** running `run_eval.py`, editing notebooks. For those, a Codespace from a
laptop or tablet.
